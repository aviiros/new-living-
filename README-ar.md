# Living Ideas — حزمة بناء تطبيق Android (APK)

هذه الحزمة تحوّل مكتبة Living Ideas إلى تطبيق Android بنفس الواجهة والميزات، باستخدام **Capacitor**. فيها مشروع Android جاهز، وطبقة منصة تعيد تنفيذ وظائف النسخة المكتبية داخل الهاتف، وسكربتات بناء.

> **حالة الاختبار بصراحة:** اختبرتُ الجزء البرمجي (طبقة المنصة والواجهة) في Chromium وهو محرك WebView نفسه: الاستيراد والقراءة والتظليل والـPDF والصوت والنسخ الاحتياطي والتخزين وعرض الهاتف. **لم يُبنَ الـAPK ولم يُجرَّب على جهاز Android فعلي** لأن بيئتي لا تملك Android SDK. إن ظهر خطأ أثناء البناء أو التشغيل فأرسل لي نصه لأصلحه.

## جديد في الإصدار 2.1
- **الصيغ:** صار التطبيق يقرأ EPUB وPDF وMOBI وAZW3 وFB2 وCBZ (القصص المصورة) وTXT وHTML والصوتيات. الملفات المحمية بحقوق النشر (DRM) لا تُفتح.
- **اقتباس اليوم:** بطاقة في الرئيسية تعرض اقتباساً من تظليلاتك وملاحظاتك، مع «اقتباس آخر» و«مشاركة كصورة» بختم Living Ideas. ويمكن تفعيل **إشعار يومي** بالاقتباس من «أهداف القراءة».
- **الإنجليزية:** زر EN/ع ظاهر في أعلى الشاشة.

## ما الذي تحتاجه؟ اختر طريقة واحدة

### الطريقة ١ — بدون تثبيت أي شيء (الأسهل): GitHub Actions
1. أنشئ حساباً على github.com، ثم مستودعاً جديداً (خاصاً يكفي).
2. ارفع محتويات هذا المجلد كلها إلى المستودع (سحب وإفلات من المتصفح يعمل).
3. افتح تبويب **Actions** ← **Build Android APK** ← **Run workflow**.
4. بعد 5–10 دقائق افتح التشغيل واحمل الملف من **Artifacts**: `Living-Ideas-debug-apk`.
5. انسخه إلى الهاتف وافتحه (فعّل «تثبيت من مصادر غير معروفة» إن طلب).

### الطريقة ٢ — على جهازك بأمر واحد
المتطلبات: **Node 18+**، و**JDK 17**، و**Android Studio** (لأنه يثبّت Android SDK).
```
npm install
npm run apk          # يبني APK تجريبياً قابلاً للتثبيت
```
الناتج: `dist/Living-Ideas-debug.apk`. على Windows يمكنك أيضاً النقر المزدوج على `build-apk.bat`، وعلى لينكس/ماك `./build-apk.sh`.

### الطريقة ٣ — عبر Android Studio
```
npm install
npm run sync         # يجهّز الواجهة ويزامن مشروع Android
npm run open         # يفتح المشروع في Android Studio
```
ثم من القائمة: **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**، أو شغّله مباشرة على هاتف موصول (زر ▶).

## توقيع نسخة نهائية (Release)
```
keytool -genkey -v -keystore android/app/release.keystore -alias living -keyalg RSA -keysize 2048 -validity 10000
```
أنشئ الملف `android/key.properties`:
```
storeFile=release.keystore
storePassword=كلمة_المرور
keyAlias=living
keyPassword=كلمة_المرور
```
ثم `npm run apk -- --release` ← `dist/Living-Ideas-release.apk`. **احتفظ بملف المفتاح وكلمات المرور في مكان آمن؛ بدونه لا تستطيع تحديث التطبيق لاحقاً.** (في GitHub Actions: أضف الأسرار `KEYSTORE_BASE64` و`KEYSTORE_PASSWORD` و`KEY_ALIAS` و`KEY_PASSWORD` فيُبنى الإصدار الموقّع تلقائياً.)

## كيف تعدّل التطبيق؟
- الواجهة والسكربتات في المجلد `web-src/` (`library.html`, `reader.js`, `player.html`, `pdfviewer.html`, `i18n.js`). بعد التعديل نفّذ `npm run sync` ثم ابنِ.
- كتب البداية في `web-src/seed/` (ملفات HTML + `manifest.json`)؛ احذف منها ما لا تريد أو أضف كتبك.
- الاسم والمعرّف في `capacitor.config.json`. (تغيير `appId` بعد إنشاء المشروع يتطلب تعديل `applicationId` في `android/app/build.gradle` أيضاً.)
- الأيقونة وشاشة البداية في `android/app/src/main/res/` (مولّدة من شعارك).

## كيف تعمل؟ (باختصار)
النسخة المكتبية تعتمد على «العملية الرئيسية» في Electron. في Android أعاد الملف `platform/platform-android.js` تنفيذ الواجهة البرمجية نفسها `window.api`، فتعمل الواجهة دون تغيير:

| الوظيفة | المكتبي (Electron) | Android |
|---|---|---|
| تخزين المكتبة والكتب | ملفات في مجلد المستخدم | IndexedDB داخل التطبيق |
| عرض الكتاب | بروتوكول `book://` | إطار `srcdoc` مع عزل تخزين كل كتاب ببادئة خاصة |
| إضافة الكتب | نافذة اختيار / سحب وإفلات | منتقي ملفات النظام |
| EPUB / PDF / صوت | في العملية الرئيسية | في الواجهة (JSZip وpdf.js وعنصر الصوت) |
| تصدير الملاحظات والنسخ الاحتياطي | مربع حفظ | قائمة المشاركة (احفظ في الملفات أو Drive) |
| الإشعارات | إشعارات النظام | LocalNotifications (التذكير اليومي يصل حتى والتطبيق مغلق) |
| زر الرجوع | Alt+← / Ctrl+L | زر الرجوع في Android (يغلق الكتاب ثم يعود للرئيسية) |

## حدود تعرفها قبل الاستخدام
- لا سحب وإفلات ولا «فتح باستخدام» لملفات HTML من خارج التطبيق؛ الإضافة من زر «إضافة كتاب».
- النسخة الاحتياطية تُبنى في الذاكرة؛ للمكتبات الكبيرة جداً (مئات الميغابايت) قد تكون ثقيلة على هاتف ضعيف.
- بياناتك داخل التطبيق: إزالة التطبيق أو «مسح البيانات» تحذفها، فاستعمل النسخ الاحتياطي.
- أدنى إصدار: Android 5.1 (API 22)، والأفضل Android 8+ مع تحديث «Android System WebView».
- الإخفاء التلقائي لشريط القارئ (الدبوس) أقل فائدة على اللمس؛ الشريط الثابت هو الافتراضي.

## استكشاف الأخطاء
- **`SDK location not found`**: عيّن `ANDROID_HOME` أو افتح المشروع مرة في Android Studio.
- **`Unsupported class file major version`**: استعمل JDK 17.
- **شاشة بيضاء عند التشغيل**: نفّذ `npm run sync` ثم أعد البناء، وتأكد أن `www/index.html` موجود.
- **فشل تنزيل Gradle**: يحتاج البناء الأول إنترنت لتنزيل Gradle والمكتبات (بعدها يعمل أسرع).

الأطراف الثالثة وتراخيصها في `THIRD_PARTY.md`.
